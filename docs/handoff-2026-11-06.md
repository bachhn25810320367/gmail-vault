## 6. Luật style/lint bắt buộc (đã vấp 4 lần, đừng lặp lại)

- `cargo fmt` là gate: viết ≤100 cột, method chain dài thì mỗi method một dòng. Không để agent nào push code chưa qua `cargo fmt`.
- Clippy `-D warnings --all-targets` đã bắt: `collapsible_if` (dùng let-chain `if let Some(x) = a && cond`), `unnecessary_sort_by` (`sort_by_key`), `derivable_impls` (`#[derive(Default)]` + `#[default]`), `field_reassign_with_default`, `large_enum_variant` (bọc `Box`), `too_many_arguments`, `needless_as_bytes`, `type_complexity` (đặt type alias cho tuple `sqlx::query_as`).
- Scaffolding do plan viết sẵn hay làm fail clippy: import thừa trong test, field không đọc → xoá hoặc `#[allow(dead_code)]` kèm lý do.
- Thêm dependency mới thì phải chạy `cargo metadata` (hoặc bất kỳ lệnh cargo nào) để refresh `Cargo.lock` rồi commit luôn.
- Test crypto Argon2id 64 MiB chạy ~35s là bình thường, đừng tưởng treo.
